Analyse every run, in seconds

S3analyse loads, visualises and compares reservoir simulation results from every major simulator — multi-million cell models and hundreds of runs, in one workspace.

Explore the features Python scripting

Fast

Multi-million cell models load in seconds, and hundreds of runs can be loaded and plotted together without leaving the application.

Simulator support

Eclipse, Nexus, CMG, tNavigator, METEOR, UTCHEM and more — read natively, so cases from different simulators sit side by side in the same project.

Includes workflows

Dashboards for common analysis tasks, one-click export to Office, and a Python API that can drive the whole application for batch processing.

What S3analyse does

Multi-simulator support Load Eclipse, Nexus, CMG, tNavigator, METEOR and UTCHEM cases into one project.3D and 2D grid display Interactive reservoir grids with wells, perforations, cut planes and timestep playback.Ensemble plotting Load hundreds of runs and plot them together to see the spread across realisations.Dashboards Cross plots, Pearson correlation, radar, well statistics and cumulative distribution panels.NPV view and designer Flexible net present value analysis per case, and NPV across a full ensemble.Export to MS Office Send the active plot or dataset straight to Excel, Word or PowerPoint.Python scripting Automate workflows and batch processing, and save a whole session as a replayable script.History matching Compare simulated against observed data, with mismatch analysis and quality factors.
