Python scripting

Drive S3analyse from Python to automate workflows and batch processing.

S3analyse exposes a Python API that can query and control a running instance — loading data, creating plots, applying calculations and reading case state. Scripts are the primary way to automate repetitive analysis and to capture a workflow so it can be run again.

Script files use the .s3py extension and run against a bundled Python runtime, so there is no separate Python installation to manage.

A minimal script

from load_pythonapi import load_pythonapi
load_pythonapi()
from PythonAPI.APIs import Analyse

project = Analyse.DataCentre.ActiveProject
plot = Analyse.Display.CreateLinePlot()

What the API covers

  • Sessions and loading — start a session, load cases and observed data
  • Query — projects, cases, vectors, wells, producers and injectors, timesteps
  • Plot creation — line, histogram, line analysis, grid display, scatter, dashboard, multi-plot, RFT, mismatch, table and VFP plots
  • Styling — axes, legends, titles, colours and series appearance
  • 3D grid control — view angles, cut planes, clipping, legends, thresholds, ternary
  • Calculations — create, associate variables, apply across cases
  • Regions — leaf, threshold and boolean composite regions
  • Resampling — fixed-interval and case-based
  • Export — send results to Office

Saving a session as a script

An entire project or session can be saved as a Python script rather than a binary project file. Re-running it rebuilds the analysis, which makes a study reproducible and easy to re-apply to a new set of runs.

Objects are addressed by case name, object name or simulator-assigned number — never by internal identifiers — so a script written today still works against a reloaded project.
