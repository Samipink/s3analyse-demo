Analysis Tools

S3analyse provides a suite of powerful analysis tools designed to enhance reservoir simulation post-processing.

Analysis Tools

Overview

S3analyse provides a suite of powerful analysis tools designed to enhance reservoir simulation post-processing. These tools allow users to derive new insights, perform custom calculations, and extract meaningful metrics from complex simulation data.

The main Analysis Tools include:

Calculations

Calculations allow the creation of new vector properties using custom formulas based on existing data. Calculations can be applied across multiple cases, wells, or timesteps, and support a wide range of mathematical functions including sums, averages, and conditional logic. Calculated vectors are integrated into the Project View and can be used in plots and dashboards.

Layer Analysis

Layer Analysis will Summarize or average grid data across layers to produce single-layer representations. This is particularly useful for visualizing vertical trends or aggregating properties like porosity or saturation. Layer Analysis supports pore volume weighting and flexible layer selection.

Regions

Regions will define and manage spatial subsets of the grid using:

  • Threshold Regions: Based on value ranges of grid properties.
  • Numeric Regions: Derived from simulation inputs such as PVT or saturation regions.

These regions can be used for filtering, plotting, and targeted analysis.

Fluid In Place Calculations

Fluid In Place Calculations will automatically compute in-place volumes (oil, gas, water) at surface conditions for each timestep. Results are weighted by pore volume and presented as SUM and AVERAGE values, which can be plotted over time.

NPV Calculations

NPV Calculations will perform Net Present Value analysis on a case/cases. An interactive chart is presented where income and costs can be input and the results presented in a chart.

Mismatch Analysis

Mismatch Analysis compares simulated results against the observed (historical) data loaded with a case. The analysis is presented as an interactive dashboard listing the cases ranked by their fit to the historical data and charts showing the comparison between simulated and observed properties.

Case Comparison

Case Comparison gives an interactive dashboard comprising a side-by-side numerical and graphical comparison of the results from any two loaded cases.
