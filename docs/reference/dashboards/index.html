Dashboards

S3analyse can be used to create Dashboards that provide a powerful way to visualize and analyse simulation cases, as especially ensembles.

Dashboards

Overview

S3analyse can be used to create Dashboards that provide a powerful way to visualize and analyse simulation cases, as especially ensembles. They consist of a customizable layout of multiple linked charts, offering a broad overview of simulation outputs and derived metrics.

Key Features

There are a number of features to Dashboards:

  • Widget-Based Design: Each chart is a Widget that can be added, removed, or customized.
  • Custom Layouts: Users can design the arrangement of charts to suit specific analytical needs.
  • Interactive Filtering: Dashboards include filters based on summary data properties, allowing users to focus on subsets of cases.
  • Ensemble-Based Visualization: Dashboards are designed to work with multiple simulation cases, enabling comparative analysis.

Creating Dashboards

Creating a Dashboard is started by with the User Dashboard button in the Home Ribbon Tab. Clicking this button will create a new Dashboard in the Display Area.

To this new Dashboard Widgets can be added to construct a Dashboard display. Widgets are added by clicking on the corresponding chart types in the Design Ribbon Tab. Each new widget will be added to the last row of the Dashboard, making a new row if there are already a number of widgets in the last row equal to the Max Columns value in the Tiles group of the Design Ribbon Tab.

Available Dashboard Widgets

Each widget represents a different type of chart or analysis:

  • Cross Plot
    • Visualizes relationships between two variables.
    • Supports parameter-based axes (e.g., from .paramsfiles).
  • Cumulative Distribution Plot
    • Shows distribution of values across cases.
    • Includes overlays for P10, P50, and P90.
  • Ensemble Summary Plot
    • Displays summary trends across all cases.
    • Supports overlays like min, max, average.
  • Grid Property Plot
    • Visualizes spatial properties from grid data.
  • Pearson Coefficient Plot
    • Shows correlation between input parameters and output metrics.
  • Radar Plot
    • Compares multiple metrics in a radial format.
  • Well Statistics Plot
    • Summarizes well-level performance metrics.

Widgets are defined by a chosen property and, in some cases, a particular value for that property.

Modifying Dashboards

The Dashboard and its Widgets have an extensive list of settings to customise their appearance and how the data is used.

Dashboard Design Tools

The layout of the Dashboard and the addition of widgets is controlled from the Design Ribbon Tab. From this it is possible to:

  • Set the number of widget columns in the Dashboard layout.
  • Add widgets from a panel of available charts.

Dashboard and Widget Settings

Appearance settings are available from the Dashboard Settings.

The settings for the individual widgets are also available:

  • Cross Plot Settings
  • Cumulative Distribution Plot Settings
  • Ensemble Plot Settings
  • Grid Property Plot Settings
  • Pearson Plot Settings
  • Radar Plot Settings
  • Well Statistics Plot Settings

Updating Dashboards

The data and its point of interest are available to set for each widget chart type. By default the charts are set to the final Field Oil Production Total or final Well Oil Production Total values as necessary, or the Porosity for map properties.

Each widget chart has these settings shown when the mouse cursor is hovering over the chart. They allow the selection of property or setting to update the chart.

Freeze Plot Axes

The Dashboard Filters pane is available when the Dashboard is active. This allows the axis range to be fixed and prevents a new range being applied when updating the chart data based on the filter.

Filtering Options

Dashboards support advanced Filtering. This is achieved with:

  • Project-Wide Filter: This allows case filtering for multi-case model from a global filter.
  • Summary Property Filter: This allows case filtering based on Summary properties for only this Dashboard.

Any changes to the list of cases will be reflected in the widget charts.

Exporting Dashboards

Dashboards can be exported with the Report Feature.

Scripts and Dashboards

Dashboards are supported by Python Scripting.

Use Cases

Suggested use cases for Dashboards are:

  • Compare field development scenarios.
  • Assess uncertainty across ensemble runs.
  • Identify correlations between input parameters and outcomes.
  • Visualize well performance across time and cases.
