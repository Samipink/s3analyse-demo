Thresholds

Thresholds let you filter and highlight cells in a Grid Display based on the value of a chosen property, showing only the cells that meet criteria you define.

Thresholds

Overview

Thresholds let you filter and highlight cells in a Grid Display based on the value of a chosen property, showing only the cells that meet criteria you define.

An example of a Threshold based on a FIPNUM value of 1.

Accessing the Grid Thresholds

You can access the Grid Threshold Settings through the grid display interface:

  1. Open the Grid you wish to customize
  2. Double left-click on the Grid
  3. The Grid Editors dialog will be displayed
  4. Select Threshold Settings from the Treeview.

What Grid Thresholds Do

A threshold is made up of one or more items, each assigned to a chosen property with a value range set on a slider. Any item can be inverted, so it keeps everything outside its range instead of within it, and multiple items are combined using AND, OR or XOR logic to build up more specific criteria. Cells that don't satisfy the combined condition are hidden from the grid, and the effect is applied instantly as you adjust the settings.

A threshold setup can be saved as a named Region so it can be reapplied to other grids, or reused elsewhere in the application, without rebuilding it from scratch.

Why Use Grid Thresholds

  • Highlight or isolate cells that meet a specific criterion, such as saturation above a given value or pressure below an abandonment limit.
  • Build up more specific criteria by combining several thresholds with AND, OR, or XOR, for example to spot cells with both high oil saturation and high permeability.
  • Save a threshold setup as a named Region so it can be reused on other grids, or in tools such as Histograms and Grid Scatter Plots.
  • See the effect of a threshold change on the grid instantly, which makes it easy to explore cut-off values interactively.

How to Use Thresholds

Thresholds can be defined in a Grid Display and then exported for reuse and filtering data in other Charts:

  1. Open the Threshold Settings for the grid, as described above, and check On to enable the display of Thresholds.
  2. Using the blank Threshold item already added to the list, choose the property it should be based on, e.g. FIPNUM, Pressure, or Saturation.
  3. Set the value range for that item using the slider, or by typing values directly into the numeric fields. The Grid Display updates instantly to show only the cells within the range.
  4. If you want to keep everything outside the chosen range instead, select Invert Item on that item.
  5. Repeat to add further items for other properties or ranges. Use each item's Operator Selection to combine it with the previous item using AND, OR or XOR, building up a more specific combined condition.
  6. Use Reset or Remove on an item, or Invert All, Reset All or Remove All, to adjust or clear the Threshold as you refine it.
  7. Once the Threshold gives the result you want enter a name in the Region box and click Save. It will now be stored as a named Region so it can be re-applied to other grids or used in tools such as Histograms and Grid Scatter Plots. See Threshold Regions for details.

Saved Thresholds can be found under the Regions node of the Project View.

For a worked example showing how selecting, inverting and combining items with AND, OR and XOR affects the grid, see the Threshold Region Example.
