Treeview Elements

One of the main features of S3analyse is the user friendly way in which data is presented to the user.

Treeview Elements

Overview

One of the main features of S3analyse is the user friendly way in which data is presented to the user. The Project View gives a summary of the loaded data. The following sections detail how what is available from the data stored in this treeview.

The selection options are context specific. The options for each context are:

  • Project Folder
  • Case Filter
  • Cases
  • Grid
  • Init
  • Table
  • Summary
  • RFT
  • Solution
  • Observed Data Files
  • Calculated Data
    • Calculations
    • Fluid In Place
    • Layer Analysis
    • Opportunity Index
    • Regions

Element: Project Folder

Each loaded case or multi-case will be collected into a Project and any associated data will be contained within this Project Folder.

The Project Folder node has controls for affecting the data set as a whole.

From the Project Folder node:

Resample: Clicking this will launch the Resample Settings.

Select Well List: Any saved Well Lists will be available for selection from this drop-down list. By default all the wells are included in the data set.

Open Well List Manager: Clicking this button will launch the Well List Manager.

Apply Well List: Toggling this button will apply the currently selected Well List to the data set.

Context Menu

The context menu for the Project Folder is:

Open Containing Folder

This will open Windows Explorer at the location of the loaded case for the chosen project.

Add Observed Data…

This will open a file browser to select one or more text files containing observed data to associate with this project. See Text Files for the supported formats.

Delete Project

This will remove the project from S3analyse and any associated charts.

Element: Case Filter

When a project contains multiple cases the Case Filter is available in the Treeview. Filters can be applied to view only a selected subset of the loaded Cases.

The default filter is "*" which matches everything. If the filter definition fails to match at least one Case then no Cases are selected.

Filter Wildcards
  • “*” matches all
  • “?” matches a single character
  • "#" matches a single digit character

Filter elements are separated by commas or semicolons.

The filter is applied/removed by clicking the Toggle Filter .

Clicking the Advanced Filter Settings expands the Project-Wide Filter on the right of the window, allowing more detailed filter options to be applied.

Element: Cases

When a project contains multiple cases the Cases is available. It lists all the loaded Cases for this project, subject to Case Filtering.

The currently “Active” case is shown in parentheses on the parent Cases node. It is also indicated by bold highlighting in the expanded Cases list. By default, the first Case is the “Active” case.

To select a different Active Case, expand the Cases branch and click the dot to the right of the required Case.

Each Case has a context menu with Open Containing Folder. This will open Windows Explorer at the location of the loaded case for the chosen project.

Element: Grid

The Grid node lists the main grid, usually ROOT, and any Local Grid Refinements (LGRs) present in this model. Each treeview entry shows the grid dimensions.

Double-clicking on a grid will produce a new Grid Display of the default or first Solution property in the Display Area.

Context Menu

The context menu for the Grid node is:

View Grid

This will create a Gird Display of the first grid, usually the ROOT, with the default map property.

View Grid Details

This will present the Grid Details dialog.

Export Eclipse EGRID

This will output the loaded grid(s) as an Eclipse EGRID formatted file.

Export Eclipse GRID

This will output the loaded grid(s) as an Eclipse GRID formatted file.

Element: Init

The Init node contains initial map properties of the grid (e.g. porosity and permeabilities).

Double-clicking on a Init property will produce a new Grid Display of the property in the Display Area for the main grid.

Context Menu

The context menu for an Init property is:

Grid <gridname> with <property>

This will create a Gird Display of the grid gridname with the chosen INIT property.

Histogram for <property> in <gridname> Grid

This will create a Histogram of the grid gridname with the chosen INIT property.

The submenu presents the other available grids.

Line Analysis for <property> in <gridname> Grid

This will create a Line Analysis of the grid gridname with the chosen INIT property.

The submenu presents the other available grids.

Scatter Plot for <property> vs ...

This will create a Scatter Plot of the chosen INIT property.

The submenu lists the other INIT properties to plot the chosen INIT property against.

Element: Table

The Table node contains Table data for the model (e.g PVT tables, Saturation tables, etc.).

The table types are listed in the Table node. Each table type contains a list of the table indices.

Double-clicking on a table index produces a Table Data Chart in the Display Area of the corresponding Table data corresponding chart.

Element: Summary

The Summary node contains Summary or Plot data for the model (e.g. Field data , Well data, etc.).

The Summary data classes are list in the Summary node. Each class may contain sub-folders of members (e.g. wells) as appropriate. Further sub-folders are necessary for some classes (e.g. Completion data).

Double-clicking on a Summary property will produce a new Line Plot of the property against Time in the Display Area.

Context Menu

The context menu for a Summary property is:

Plot <property> vs Time

This will create a Line Plot of the chosen property against the Time property.

Plot <property> for all <members>

This will create a single Line Plot of the chosen property against Time for all members of the Summary Class, where appropriate, i.e. all wells, groups, etc.

Plot <property> for Well List: <welllist>

This will create a single Line Plot of the chosen property against Time for all wells included in the Well List. This is only available for well properties.

Plot <property> for all cases

This will create a single Line Plot of the chosen property against Time for all loaded cases. This is only available for multi-case models.

Plot <property> for filtered cases

This will create a single Line Plot of the chosen property against Time for the Filtered cases. This is only available for multi-case models.

Plot <property> vs ...

This will create a Line Plot of the chosen property against an appropriate property chosen from the submenu.

Element: RFT

The RFT node contains Repeat Formation Test (RFT) data and Production Logging Tool (PLT) data: well pressure and depth measurements recorded at specific timesteps.

If a case has no RFT file of its own, an equivalent data set is derived automatically from the loaded Grid, Init and Solution data, so the RFT node is available even when no dedicated RFT file has been loaded.

Data under the RFT node is arranged as Timestep > Well > Branch > property (e.g. PRESSURE, DEPTH). Wells with multiple laterals or perforated intervals present a separate Branch entry for each.

Double-clicking a RFT property will open a new RFT Plot in the Display Area showing a property-versus-depth chart alongside a data grid of the values.

Context Menu

The context menu for a RFT property is:

Display RFT Chart for <property>

This will create a RFT Plot of the chosen RFT property.

Element: Solution

The Solution node contains dynamic map properties of the grid (e.g. Pressure, Oil Saturation, etc.).

The Solution timesteps are listed in the Solution node. Each timestep contains its properties.

Double-clicking on a Solution property will produce a new Grid Display of the property in the Display Area for the main grid.

Context Menu

The context menu for a Solution property is:

Grid <gridname> with <property>

This will create a Gird Display of the grid gridname with the chosen Solution property.

Histogram for <property> in <gridname> Grid

This will create a Histogram of the grid gridname with the chosen Solution property.

The submenu presents the other available grids.

Line Analysis for <property> in <gridname> Grid

This will create a Line Analysis of the grid gridname with the chosen Solution property.

The submenu presents the other available grids.

Scatter Plot for <property> vs ...

This will create a Scatter Plot of the chosen Solution property.

The submenu lists the other Solution properties to plot the chosen Solution property against.

Element: Observed Data Files

The Observed Data Files node will list any loaded data files containing Observed or History Data.

This node lists the loaded files. Within each file entry is a list of the properties, arranged as Summary or Solution as appropriate.

Element: Calculated Data

The Calculated Data node lists the available analysis tools for the selected project.

This node contains the:

  • Calculations: User defined calculations.
  • Fluid In Place: Fluid in Place calculations for the model.
  • Layer Analysis: Layer Analysis of the grid.
  • Opportunity Index: Calculated Opportunity Index properties.
  • Regions: Defined regions of the map and grid. This includes Threshold Regions and Numeric Regions (PVT regions, etc.).

Calculations

Calculations allows new data properties to be derived from existing data. The newly created property is added to the treeview and can be used in the same way as any other property. A Calculation function could be used, for example, to find the ratio of gas to oil production or to find the difference between the production rates of two separate simulator runs.

Double-clicking the Designs node brings up the Calculations dialog, where new calculations can be added.

Fluid In Place

The Fluid In Place Calculations are defined in the Fluid In Place node. This lists the Gas, Oil and Water In Place values at Surface Conditions for each simulation timestep, weighted by Pore Volume.

The SUM value is the total In Place volume added across all cells in the region. The AVERAGE value is the SUM divided by the number of active cells in the region to give the average cell contribution.

Double-clicking on a Fluid In Place property will produce a new Line Plot of the property against Time in the Display Area.

Layer Analysis

Layer Analysis allows grid map data to be analysed either by summing or averaging data over layers.

From the Layer Analysis node:

Add Layer Analysis: This creates a new Layer Analysis that is added as a new Layer Analysis item to the bottom of the list.

From the individual Layer Analyses nodes:

Delete Layer Analysis: This delete the Layer Analysis.

Show Layer Analysis Settings: This presents the Layer Analysis dialog, where you can select the required settings.

The node is named with an index, 1 in the example above. The node also has a label that lists the layers that the analysis sums/averages, (1 - 14) or layers 1 to 14 in the above example.

Each Layer Analysis contains a single-layer Grid node and corresponding Init and Solution nodes containing the summed or averaged properties. These are treated as Grid, Init and Solution Treeview Elements.

Opportunity Index

Opportunity Index offers data properties output from a calculation of the Opportunity Index.

Show Opportunity Index Settings: This launches the Opportunity Index Settings.

The Opportunity Index contains data properties of the calculation for each Grid, Layer Analysis and Solution Timestep, available to create a Grid Display as normal.

Regions - Threshold Regions

Threshold Regions are defined subsets of the grid cells defined by a range of map cell values.

From the Threshold Regions node:

Add Threshold Regions: This creates a new Threshold that is added as a new Threshold Region item under the Threshold Regions node

From the individual Threshold nodes:

Delete Threshold Region: This delete the Threshold.

Show Threshold Region Settings: This presents the Threshold Settings dialog, where you can select the required settings.

Double-clicking on a Threshold Region will produce a Grid with the Threshold applied.

Regions - Numeric Regions

The numeric regions defined by the loaded data (e.g. PVT, Saturation or Fluid in Place regions) are available from the Numeric Regions node. Each Numeric Region node is labelled with its associated property definition and the number of different regions defined.

Double-clicking on a Numeric Region node or property node will produce a Grid of the numeric property.

Context Menu

The context menu for a Numeric Region node or property node is:

Grid <gridname> with <property>

This will create a Gird Display of the grid gridname with the chosen numeric property.

Create Threshold Region

For Numeric Region property nodes, e.g. FIPNUM #1, this will create a new Threshold region of (FIPNUM = 1) and add it to the Threshold Region node, named "Threshold <property> #<index>", e.g. "Threshold FIPNUM #1".

For Numeric Region nodes, e.g. FIPNUM, this will produce a dialog where property indices can be selected to create a new Threshold Region.

Indices can be selected from the list of available values. Clicking OK will produce a new Threshold Region. Cancel will abort the operation.

A new region will be added to the Threshold Region node, named "Threshold <property> #<index list>", e.g. "Threshold FIPNUM #1,3".
