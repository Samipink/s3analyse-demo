Grid View Tab

The Grid View tab contains the common settings for the appearance of the active Grid.

Grid View Ribbon Context Tab

Overview

The Grid View tab contains the common settings for the appearance of the active Grid.

Access and Visibility

The Grid View tab appears in the ribbon when a Grid display is active.

The tab updates its content based on what you select.

Main Functional Groups

The Grid View ribbon tab is organized into several key groups:

Colours Group

Invert

This inverts the colours of the background and the axes and grid colouring.

Colours

Allows colour selection for various aspects of the grid which can be chosen.

This includes the Active Cells, Inactive Cells, Background, Grid Wireframe and Gird Wall.

Cell Display Group

LGR

Toggles the display of the Local Grid Refinements (LGRs), if they exist in the model.

Active Cells

Toggles the display of Active Cells.

Inactive Cells

Toggles the display of Inactive Cells.

Cell Information

Displays cell information as a tooltip. Control of what is included in the tooltip is available in the Tooltip Settings for the Grid.

Display Group

Wireframe

Toggles the display of the grid cell outline.

Cell Faces

Toggles the display of the grid cell faces.

Lighting

This turns on the lighting facility, which gives a feeling of depth to the grid display.

Transparency

Set the transparency level of the grid.

Changing the transparency of the cells allows you to see inside the grid for details which would you would otherwise be unavailable to view. Valid figures lie between 0 (opaque) and 100 (totally transparent).

Views Group

The Layers settings allow easy switching between the grid display modes. These are:

3D All View the full grid in 3D
Single Layer View a single chosen layer/section in 3D
2D View View a single chosen layer/section in 2D plan view

When using Single Layer or 2D View the layer/section displayed can be selected from the dropdown menus. Which slice and what plane (XY, XZ or YZ) can be selected. For 2D View the top, middle or bottom cell faces can be shown.

Axis Group

The orientations of the X, Y and Z axis can be inverted or mirrored:

Flip X Toggle the direction of the X-axis
Flip Y Toggle the direction of the Y-axis
Flip Z Toggle the direction of the Z-axis

Wells Group

Show Wells

Toggle the display of the wells. This includes markers, labels and perforations.

Labels

Toggle the display of well labels.

Perforations

Toggle the display of well perforations.

Markers Above

This shows the well markers and labels above the grid bounding box.

Scaling Group

Mode

Predefined scaling modes can be applied to the grid. These are:

Arbitrary Scaling mode where the user Scale Factors are applied to the grid
Fit Window Scaling mode where the grid is adjusted to occupy the entire available display area
Square Scaling that ensures that the grid maintains equal scaling across all axes, resulting in a uniform square grid
True Scale Scaling mode where the grid maintains accurate, real-world proportions
Z Scaling

Set the scaling of the Z-axis. This helps to see the grid in more detail if the grid layers are compressed.
