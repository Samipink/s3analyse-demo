Chart Data Tab

The Chart Data tab contains the settings for the data used on the active Line Plot.

Chart Data Ribbon Context Tab

Overview

The Chart Data tab contains the settings for the data used on the active Line Plot.

Access and Visibility

The Chart Data tab appears in the ribbon when a suitable Line Plot chart is active.

The tab updates its content based on what you select.

Main Functional Groups

The Chart Data ribbon tab is organized into several key groups:

Options Group

Show Observed Data

Toggles the display of observed data, if there is observed data loaded for the project.

Hide Repeated Observed Data

Toggles the suppression of the duplication of observed data on a chart when the same observed data is associated in with multiple displayed properties. Requires observed data loaded for the project.

Search Group

The indexing options are presented to offer quick navigation of the data set.

Index By

Select the data property by which to index by, or indexing mode. This includes:

  • Index by Case

This sets the search to be indexed by the case. Available only when multiple simulation cases are loading into a project.

  • Index by Member

This sets the search to be indexed by the member, such as well name.

  • Index by Submember

This sets the search to be indexed by the submember, such as completion location for a well.

  • Index by Name

This sets the search to be indexed by the property name.

The current value for the active chart for the chosen index is shown on the ribbon as Current.

Use Project Filter

When enabled this option will limit the indexing to the data defined with the Project-Wide Filter.

Indexing controls

The search has three options for applying the indexing:

Replace

Clicking the Replace option will update each property on the active Line Plot chart with the next item in the list based on the indexing selection.

Instead of the next item, selecting an item from the Select Item... drop down list of indexed values allows the choice of the index to update the active chart.

New

Clicking the New option will create a new chart with the same line(s) as the active Line Plot chart, updated with the next item in the list based on the indexing selection.

Instead of the next item, selecting an item from the Select Item... drop down list of indexed values allows the choice of the index with which to create a new chart.

Append

Clicking the Append option will append a new line for each property on the active Line Plot chart with the next item in the list based on the indexing selection.

Instead of the next item, selecting an item from the Select Item... drop down list of indexed values allows the choice of the index with which to create the new line(s) to append to the active chart.

Search Direction Buttons

Wrap

This option allows the indexing to wrap around to the beginning/end of the list when indexing to the next item from the bottom/top of the list.

Search Direction

These buttons changes the order that the search operations moves in.

If the Up Arrow is selected the search will move up the alphanumeric list, and if the Down Arrow is selected searches downwards.
