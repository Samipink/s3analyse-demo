Chart View Tab

The Chart Data tab contains the settings for the appearance of the active Line Plot.

Chart View Ribbon Context Tab

Overview

The Chart Data tab contains the settings for the appearance of the active Line Plot. The majority of these settings are also available in Line Plot Settings.

Access and Visibility

The Chart View tab appears in the ribbon when a suitable Line Plot chart is active.

The tab updates its content based on what you select.

Main Functional Groups

The Chart View ribbon tab is organized into several key groups:

Axes Group

Axis

Select the X or Y axis from the list with which to apply the axes setting to.

Width

Set the width for the selected axis.

Invert

Toggles the inversion of the axis.

Font Group

Area

Select the component of the chart from which to alter the font. Choose from chart Title, Legend or Axis from the list.

The Font and Size of the selection will be changed by the Font and Size controls

Font and Size

Select font and font size for the selected area.

Graph Group

Colours

From this dropdown select the colour of each component of the chart. This includes:

  • Line
  • Marker
  • Axis Lines
  • Axis Test
  • Graph Background
  • Plot Background
Major and Minor Grid Lines

Toggles the display of the Major and Minor grid lines

Legend Group

Show Legend

Toggles the display of the legend.

Orientation

Toggles between horizontal and vertical orientation of the legend.

Position Relative to Axes

Toggle the position of the legend to within or outside the axes boundary.

Horizontal Position

Select whether the legend is positioned on the Left or Right, and when in Horizontal Orientation, Stretch or Centre.

If Stretch, then the width of the Legend will be the width of the X-axis. Otherwise the width will be the width of the legend contents.

Vertical Position

Select whether the legend is positioned at the Top or Bottom of the axes.

Legend Limit Group

Limit Legend Items

Charts with multiple lines will produce an item in the legend for each line. This can create large and unwieldy legends as it fills to fit the space and position.

This setting toggles the application of the limit. When the limit is reached the legend is hidden.

Limit

This options sets the limit of the number of items in the legend before it is automatically hidden.

Line Type Group

Series

Select which data series line to view and alter its settings.

Line Style

Select the line style for the chosen series.

The line styles can be Solid, Dash, Dot, Dash Dot and Dash Dot Dot.

Width

Select the width for the chosen series.

Plot Type

Select the plot type for the chosen series.

The types can be Line, Scatter and Line & Scatter.

Marker

Select the marker style for the chosen series.

Size

Select the marker size for the chosen series.

Remove Selected Line

Remove the selected series from the chart.

Graph Zoom Settings Group

This group manages the Zoom history for the chart.

If the chart has been zoomed, the previous Zoom settings are remembered, and the Zoom settings can be restored using the Zoom Settings.

Navigating the Zoom history is achieved with:

First Restores first Zoom (original view)
Previous Restores the previous Zoom
Next Restores the Next Zoom in the zoom list
Last Restores the most Recent zoom
Reset Restores the default zoom and removes all the other Zoom settings
