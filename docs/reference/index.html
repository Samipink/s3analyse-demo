Includes the S3analyse help documention.

Everything below this point is imported directly from the S3analyse product help, and mirrors its own structure: the user interface tab by tab, every settings page, and each supported simulator.

Use it when you need the specific detail — what a particular control does, which setting governs a behaviour, what a dialog expects. The sections above are the guided tour; this is the manual.

In this section

Welcome to S3analyseS3analyse is Sciencesoft’s next generation reservoir simulation post-processing software package.General SettingsThe General Settings provide options to customize the behaviour of the application, how it loads data sets and actions upon loading data.The User InterfaceThe user interface is split into four main parts:Loading DataS3analyse is designed to support a wide range of industry-standard data formats, making it suitable for workflows across multiple reservoir simulators.Managing DataS3analyse has options to handle loaded data and how it is presented.Show Data In A TableThe Vector Table displays data from the project as a spreadsheet-style grid, one column per vector, with filtering to narrow down which vectors are shown, and optional statistical values per column.Chart DisplaysS3analyse can be used to quickly create Line Plot charts by double-left clicking on time series data in the Project View.Grid DisplaysS3analyse can be used to create Simulation Grids by double-left clicking on map data in the Project View.DashboardsS3analyse can be used to create Dashboards that provide a powerful way to visualize and analyse simulation cases, as especially ensembles.Analysis ToolsS3analyse provides a suite of powerful analysis tools designed to enhance reservoir simulation post-processing.Exporting ReportsS3analyse includes the ability to output any items created in the Display Area into a report.Python ScriptingS3analyse supports the creation and loading of scripts in Python, which has become the industry standard for scripting.WorkflowsA Workflow is a Python script written to be run repeatedly through the Workflow Manager, rather than loaded once from a saved session.
