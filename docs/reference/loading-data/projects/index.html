Projects and Data Loading

Projects are used to organise all loaded data into a single working session. This structure allows users to manage multiple simulation runs, sensitivity cases, and history matches within a unified environment.

Each project acts as a container for related files, making it easy to navigate between datasets, compare results, and maintain a clear overview of the modelling workflow.

When a file is loaded into a project, S3analyse automatically searches for any associated data in the appropriate folder. This includes summary files, restart files, grid definitions, and parameter sets. By detecting and loading these linked files, the system ensures that all relevant information is available for plotting, analysis, and comparison without requiring manual intervention.

This streamlined approach helps users focus on interpretation rather than file management.

Creating a New Project

Data can be loaded via drag and drop onto S3analyse or with File Open. This will create a default project for the session. Alternatively, data can be added by formally creating a new project.

This is achieved by clicking on New Project in the File Ribbon Tab or the Quick Access Toolbar. This will produce the Create a New Project dialog:

The creation process has two steps; select the data set(s) then select the data types to be loaded.

The treeview on the left lists the steps to create the project. Both Select Cases and Select Data need to be valid to create the new project. Their status is shown in the left list, defined as follows:

  • indicates a valid selection and the next step is available.
  • indicates an issue with the selection. A status message of the creation process is shown in the bottom-left of the dialog to indicate any issues.
  • indicates an undefined status. An invalid step leads to later steps as undefined.

Select Cases

The location of the data is set with Base Folder. A path can be typed into the textbox or browsed for by clicking . Clicking the will clear the entry for the Base Folder.

The Simulator can be selected to find data sets only from the chosen simulator.

The Project Name is inferred from the chosen folder, otherwise the user can set the name from the textbox.

When a valid path has been entered the Case list will be populated with any data sets found in the chosen Base Folder. The list can include subfolders of the Base Folder if Search Subfolders For Case Files is checked. Any case can be selected/deselected from the load by checking the corresponding checkbox for that case.

The Case Filter offers the ability to filter cases based on their name to aid finding the cases of interest.

Once the required case or cases have been selected clicking Next will move to the second step of Selecting Data. Alternatively, the default data selection can be used and Create Project can be clicked to create the new project and skip the Select Data step.

Select Data

Once a valid case or cases have been selected the next step is to select what data types to load for the cases.

The available data for the case or cases is shown in the left-hand treeview. Individual types can be included/excluded from the new project by checking/unchecking their corresponding checkboxes in the list.

Clicking on a data type, such as Init or Summary, will list a breakdown of available sub-components, such as properties or wells, for that data type in the right-hand list. These can be individually included/excluded for finer granularity in the load.

With a valid data selection the New Project can be created by clicking on Create Project.
