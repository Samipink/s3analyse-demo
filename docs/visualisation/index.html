Grid visualisation

Interactive 3D and 2D reservoir grids with wells, regions and timestep playback.

Reservoir grids render on the GPU resulting in fast 3D, 2D and single-layer renderings. Visualise multi-million cell models with no time lag.

The demo above shows the Cell Lines page of the Grid Editors window: cell faces, wireframe, and active/inactive cell colours. The product additionally offers axis settings, clipping planes, lighting and transparency, ternary display, threshold filtering, scale factor, viewing angles and well markers — deferred for now, see 3D grid displays for the full set.

Display controls

  • Cell display — active cells, inactive cells, local grid refinements
  • Appearance — cell faces, wireframe, lighting and transparency
  • Views — 2D, full 3D, or a single layer
  • Axes — flip X, Y or Z independently
  • Scaling — true scale, square, fit to window, or an arbitrary vertical exaggeration
  • Dual porosity — matrix, fracture, or both

Wells

Well trajectories can be drawn on the grid with labels, perforations, and markers above the reservoir so wells stay visible from any viewing angle.

Colouring and legends

Any grid property can be coloured by a selected scheme, with the legend shown on the view and limits taken from the data, the selected timesteps, or values you set yourself. Schemes can be inverted.

Ternary saturation display

Three-phase saturations can be displayed as a ternary blend, so oil, water and gas distribution is visible in a single view rather than three separate property plots.

Timestep playback

Solution properties animate through time with configurable start and end dates, playback delay, reverse and repeat, plus step controls for first, previous, next and last timestep.
